# Source figure library

Raster source figures in this directory are crops from the cited sources.
Surrounding figure numbers, captions, and slide text have been removed so
each image contains only the drawing. Editable SVG redraws are identified below.

## Busby et al., current multi-edge manuscript

Source: [`VPR3.pdf`](../../VPR3.pdf)

- `busby-multiedge-fig-1.png` — Figure 1, the graph C-tilde(5,2).
- `multiedge-cycle.svg` — Editable redraw of Figure 1 for the research note,
  with small solid vertex markers and external labels.
- `multiedge-labelings.svg` — Figure 2 redrawn with the same integer labels
  and edge multiplicities, using small solid vertex markers.
- `arithmetical-merge.svg` — Homepage construction schematic redrawn from
  `../fig-arith-merge.svg`, using small solid vertex markers.
- `busby-multiedge-fig-2.png` — Figure 2, examples on C-tilde(4,3) and
  C-tilde(4,4).

These figures come from the site owner's current manuscript.

## Busby, 2024 dynamics poster

Source: [`2024_discrete_dynamical_systems_poster.pdf`](../posters/2024_discrete_dynamical_systems_poster.pdf)

- `busby-dynamics-fig-1.png` — Figure 1, dependency graph.
- `busby-dynamics-fig-2.png` — Figure 2, state space.
- `busby-dynamics-fig-3.png` — Figure 3, maximal acyclic subgraph.
- `busby-dynamics-fig-4.png` — Figure 4, rooted maximal acyclic subgraph.
- `busby-dynamics-fig-5.png` — Figure 5, dependency graph and state space.
- `acyclic-reduction.svg` — A monochrome redraw of the first and third panels
  of Figure 3, shown side by side with small solid vertex markers.
- `dependency-digraph.svg` — Figure 1 redrawn with small solid vertex markers
  and external labels, omitting the separate graph-name label.
- `boolean-state-graph.svg` — Homepage state graph redrawn from
  `../fig-boolean.svg`, using small solid vertex markers and external labels.

These figures come from the site owner's poster.
`busby-dynamics-fig-2.png`, `busby-dynamics-fig-4.png`, and
`busby-dynamics-fig-5.png` are retained in the source archive but are no
longer displayed on the site.

## Rafimanzelat, 2025

Source: [Global Stabilization of Boolean Networks With Applications to
Biomolecular Network Control](https://www.nature.com/articles/s41598-025-97684-y)
([DOI](https://doi.org/10.1038/s41598-025-97684-y))

- `rafimanzelat-2025-fig-1.png` — Figure 1, a top-down state graph.

The figure is reproduced unchanged under
[CC BY-NC-ND 4.0](https://creativecommons.org/licenses/by-nc-nd/4.0/).
It is a general Boolean-network example and is not presented as the state
space of the site's monomial-system example.

## Glass and Wagner, 2020

Source: [Arithmetical Structures on Paths With a Doubled Edge](https://math.colgate.edu/~integers/u68/u68.pdf)
([arXiv](https://arxiv.org/abs/1903.01398))

- `glass-wagner-fig-1.png` — Figure 1, the graphs P(3,2) and P(1,5).
- `glass-wagner-fig-2.png` — Figure 2, smooth and non-smooth examples.
- `doubled-edge-paths.svg` and `doubled-edge-labelings.svg` — Redraws of the
  two figures with small solid vertex markers and external labels.

The article is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/);
the [Gettysburg College repository record](https://cupola.gettysburg.edu/mathfac/59/)
provides the license statement.
Credit: Darren Glass and Joshua Wagner. The PNG crops preserve the source
drawings. The SVG adaptations change vertex styling and label placement,
preserving the graph structure and labels.
